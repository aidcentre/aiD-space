The dataset is collected from this site [expertise search](https://studntnu.sharepoint.com/sites/o365_AIforDecision2/Shared%20Documents/Forms/AllItems.aspx?csf=1&web=1&e=94bFEj&clickparams=eyAiWC1BcHBOYW1lIiA6ICJNaWNyb3NvZnQgT3V0bG9vayIsICJYLUFwcFZlcnNpb24iIDogIjE2LjAuMTk2MjguMjAxNTAiLCAiT1MiIDogIldpbmRvd3MiIH0%3D&CID=ecc6f3a1-0009-f000-498f-6fad54aff1e0&cidOR=SPO&FolderCTID=0x012000D76C3CD00FF84E47AC7AB11583D376EE&id=%2Fsites%2Fo365_AIforDecision2%2FShared+Documents%2FGeneral%2FExpertise+finder).
In this folder, each researcher in the centre can create their own subfolder, where they upload relevant documents for the expertise finder.
It's important that every **researchers folder is labeled by their name**, since this will be the name used to identify you in the expertise search. 

## Personal Information

Researchers can add a **.txt** file to their folder with information about them and their work, so that if a researcher has relevant expertise to a certain context, these links will be shown in the expertise search. Here's the format of the .txt file:

```text
<link to google scholar profile>
<link to professional web site>
<ORCID ID>
```

It's important that you input only these 3 types of links. Any other information provided will not be shown in the expertise search.

### Example

Here's an example of this .txt file

```text
https://scholar.google.com/citations?user=kukA0LcAAAAJ&hl=en
https://www.ntnu.no/ansatte/<name>
https://orcid.org/0000-0002-1825-0097
```

## Relevant documents

Researchers can add relevant documents showing their expertise in their folder. It's important that the filetype of these kinds of documents are **PDF**.
- These documents can be **papers** or relevant **book chapters**.
- They can also be **presentations**, however then the name of the file should start with **presentation**. This is done since the expertise search will regard the expertise from these documents in a different way 

### Example

```text
my_paper_name.pdf
presentation_my_presentation_name.pdf
```
